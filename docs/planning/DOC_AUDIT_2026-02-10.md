```markdown
## Embedding Providers

Weave CLI supports **3 embedding providers**:

| Provider | Type | Cost | Dimensions | Setup |
|----------|------|------|------------|-------|
| **OpenAI** | API | $0.02/1M tokens | 1536, 3072 | API key required |
| **sentence-transformers** | Local | FREE | 384, 768 | pip install |
| **Ollama** | Local | FREE | 768, 1024 | ollama install |

### Quick Start - OSS Embeddings

```bash
# Install sentence-transformers
pip install sentence-transformers

# Re-embed collection with OSS model (20x faster than re-ingestion!)
weave collection reembed MyCollection \
  --new-embedding sentence-transformers/all-mpnet-base-v2 \
  --output MyCollection_OSS

# Compare OpenAI vs OSS embeddings
weave collection compare MyCollection MyCollection_OSS \
  --query "test query" \
  --report comparison.md
```

📖 **See [OSS Embedding Testing Guide](docs/guides/OSS_EMBEDDING_TESTING_TIPS.md)
for detailed setup and troubleshooting**
```
