## 📝 Notes

### Lessons Learned
1. **Integration tests are high value** - Uncovered many subtle bugs
2. **UUID support critical** - Many VDBs require proper ID handling
3. **Metadata serialization varies** - Each VDB has unique requirements
4. **Timing matters** - MVCC, eventual consistency need consideration
5. **Docker setup is fast** - Tier 1 services start in ~20s

### Risks
1. **Docker resource limits** - May hit RAM limits with all services
2. **Flaky tests** - Network/timing issues possible
3. **CI costs** - GitHub Actions minutes
4. **Maintenance burden** - More tests = more maintenance

### Mitigation
1. Use tiered approach (start small)
2. Robust health checks, generous timeouts
3. Run integration tests on PR only
4. Clear patterns, good documentation
