**Phase 1.2: Unit Test Template (0.5 hours)**
```go
// Example: src/pkg/vectordb/qdrant/collection_test.go
package qdrant

import (
    "context"
    "testing"
    "github.com/stretchr/testify/assert"
    "github.com/stretchr/testify/mock"
)

func TestAdapter_CreateCollection_Success(t *testing.T) {
    // Arrange
    mockClient := new(MockQdrantClient)
    adapter := &Adapter{client: mockClient}
    mockClient.On("CreateCollection", ...).Return(nil)

    // Act
    err := adapter.CreateCollection(ctx, "test", nil)

    // Assert
    assert.NoError(t, err)
    mockClient.AssertExpectations(t)
}

func TestAdapter_CreateCollection_EmptyName(t *testing.T) {
    adapter := &Adapter{}
    err := adapter.CreateCollection(ctx, "", nil)
    assert.Error(t, err)
}

func TestAdapter_CreateCollection_Timeout(t *testing.T) {
    // Test timeout scenarios
}
```

### Priority 2: Test Coverage Measurement (1-2 hours)

**Goal**: Establish baseline and tracking for test coverage

**Phase 2.1: Coverage Script (0.5 hours)**
```bash
#!/bin/bash
# tools/test-coverage.sh

echo "Running test coverage analysis..."

# Run tests with coverage for all packages
go test ./src/pkg/... -coverprofile=coverage.out -covermode=atomic

# Generate HTML report
go tool cover -html=coverage.out -o coverage.html

# Generate summary
go tool cover -func=coverage.out | tail -1

# Per-package summary
echo "\nCoverage by Package:"
go tool cover -func=coverage.out | grep -E "^github.com/maximilien/weave-cli/src/pkg/vectordb" | \
    awk '{print $1 "\t" $3}' | sort -k2 -rn
```

**Phase 2.2: CI Integration (0.5 hours)**
- Add coverage to GitHub Actions
- Upload coverage to codecov.io or coveralls.io
- Add badge to README

**Phase 2.3: Coverage Targets (0.5 hours)**
```yaml
# .codecov.yml
coverage:
  precision: 2
  round: down
  range: "50...80"

  status:
    project:
      default:
        target: 60%    # Initial target
        threshold: 5%  # Allow 5% decrease
    patch:
      default:
        target: 70%    # New code should be well-tested
```

**Success Metrics:**
- ✅ Coverage tracked in CI
- ✅ Coverage reports generated
- ✅ Baseline established for each VDB
